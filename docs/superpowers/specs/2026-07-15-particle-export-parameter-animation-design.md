# 粒子视频导出参数动画设计

## 目标

在深度 3D 与粒子溶解两套引擎的 MP4 导出流程中，允许用户同时选择多个实时参数，让它们在五秒视频内从当前值平滑变化到指定结束值。

## 交互

点击 MP4 后先打开“导出动画参数”面板。面板按当前引擎列出可安全实时更新的数值参数，每行包含：

- 启用复选框。
- 自动读取且只读的当前值。
- 用户填写的结束值。

用户可以同时启用多个参数。未启用任何参数时仍可正常导出，行为与当前版本一致。确认后开始五秒、30 FPS 的 MP4 导出；取消面板不会修改预览。

## 动画规则

- 所有已选参数从第 0 帧的当前值同步变化到最后一帧的结束值。
- 使用 `smoothstep` 缓入缓出曲线：`t * t * (3 - 2 * t)`。
- 每个结束值按该参数现有最小值、最大值进行限制。
- 导出期间仍保留时间驱动的水波、闪烁、漂移等自然动画。
- 参数动画优先于自动播放对同一参数的控制。
- 导出成功、失败或取消后，Renderer 与 React 状态都恢复到导出前的参数和画面。

## 参数范围

只允许不会触发图片解码、AI 推理、Worker 预处理或 Geometry 重建的参数。

深度 3D 引擎包括侵蚀进度、过渡带宽、粒子大小、散开量、漂移速度、深度强度、水波参数、侵入范围、边界柔化、不规则度、噪声尺度、外部离散、颜色保留、内部交错、Bloom 参数和镜头距离等实时参数。导出继续固定当前视角，因此不提供旋转速度轨道。

亮度阈值、对比度、边缘增强、透明度阈值、饱和度、深度平滑和深度层数属于结构参数，不进入动画列表。

粒子溶解引擎包括侵蚀进度、过渡带宽、粒子散开量、粒子大小、边界噪波、水波或热浪强度及频率。采样间距、模式和效果类型不进入动画列表。

## 架构

新增共享的纯函数动画模块，负责轨道定义、范围限制、缓动和指定帧参数计算。新增共享导出参数面板，由两套工作台传入各自的参数元数据和当前值。

两套 Renderer 的 `exportMp4` 接收可选动画轨道：

1. 保存导出前参数。
2. 每帧计算缓动进度。
3. 生成该帧参数并更新 GPU uniform、Bloom 或镜头。
4. 渲染并交给现有 MP4 编码器。
5. 在 `finally` 中恢复原参数。

## 错误处理与性能

- 非数字结束值不能开始导出，并在对应行显示错误。
- 导出期间禁止修改动画轨道、切换引擎或拖动普通参数。
- 每帧只创建一份小型参数对象并更新现有 Renderer，不重建粒子数据。
- 取消编码后仍必须执行参数恢复和画布尺寸恢复。

## 验证

- 使用简单纯函数测试验证多轨道插值、缓动端点、范围限制和未选择参数保持不变。
- 运行粒子专项测试、TypeScript 检查和生产构建。
- 不增加覆盖率任务或逐帧视觉回归测试。
