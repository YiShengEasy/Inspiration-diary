# 正式粒子工作台溶解预设合并设计

**状态：** 已完成对话确认，等待书面规格审阅  
**日期：** 2026-07-14  
**适用范围：** `src/features/particle-studio`

## 1. 目标

把 `demos/particle-dissolution/index.html` 中经过确认的五种溶解效果移植到正式粒子 3D 工作台，同时保留现有“人像柔边”。正式工作台最终只提供六个预设：

1. 人像柔边
2. 灰尘消散
3. 星云扩张
4. 线性扫除
5. 雾化飘落
6. 火焰涅槃

现有“风景层次、霓虹冷光、黑白雕刻、参考图同款”不再显示。独立 Demo 保留为效果参考，但正式页面不通过 iframe 或复制页面方式加载它。

## 2. 保留能力

合并后必须继续支持：

- 上传和替换图片。
- 快速深度与 AI 深度。
- 鼠标拖拽立体旋转、缩放和固定当前视角。
- 现有粒子参数面板和一键预设。
- Worker 图像预处理。
- 当前视角 PNG 与 MP4 导出。
- 图片宽高比保持和移动端粒子上限。

## 3. 架构

正式 `ParticleRenderer` 继续作为唯一渲染器。新增的效果只通过类型化的预设配置和 GPU Shader 分支实现，不创建第二套 Three.js 场景。

`ParticleParams` 增加：

- `effectMode`：`portrait | dust | nebula | linear | fog | fire`。
- `dissolveDirection`：描述边缘、中心、横向或纵向侵蚀。
- `dissolveProgress`：当前侵蚀进度。
- `dissolveBandwidth`：粒子化过渡带宽。

预设文件负责每种效果的默认参数，Shader 负责图像平面和粒子使用同一侵蚀场。这样原图、黑色侵入区域和粒子边界保持连续，不出现图层割裂。

## 4. 效果定义

### 人像柔边

保持当前正式工作台的人像效果和参数，不改变默认视觉结果。

### 灰尘消散

使用细颗粒与低幅随机散射，从不规则边缘向内部侵蚀；粒子继承原图颜色并逐渐降低透明度。

### 星云扩张

从主体附近向外扩张，过渡带更宽，粒子沿径向和低频噪声缓慢漂移，保留有限原图色彩。

### 线性扫除

使用窄过渡带沿横向推进。图像平面与粒子使用相同扫除位置，避免矩形残边。

### 雾化飘落

使用宽且柔和的侵蚀带，粒子缓慢下落并带有轻微横向扰动，整体亮度与 Bloom 保持克制。

### 火焰涅槃

从底部向上侵蚀。过渡带产生橙红燃烧边缘、热浪扭曲和向上运动的火星粒子；主体未侵蚀区域继续显示原图，不把整张图统一染成橙色。

## 5. 参数与性能

- 普通拖动参数只更新 uniform，不重建几何和图像采样。
- 只有粒子密度、深度层数、图像采样阈值等结构参数触发 Worker 重建。
- 预设切换若不改变结构参数，直接复用现有粒子 Buffer。
- 动画使用现有渲染循环和时间 uniform，MP4 导出复用同一帧推进逻辑。
- 不增加常驻 CPU 粒子模拟，不为火焰单独创建第二个粒子系统。

## 6. UI

预设按钮按以下顺序显示：

```text
人像柔边 / 灰尘消散 / 星云扩张 / 线性扫除 / 雾化飘落 / 火焰涅槃
```

选择预设后继续允许用户调整侵蚀范围、过渡宽度、散射、粒子大小、波动、颜色保留、深度和 Bloom。效果专用参数映射到现有控制项；本轮不新增复杂的二级面板。

## 7. 错误与兼容

- 旧预设 ID 从 UI 移除，不保存新的兼容别名；刷新页面使用“人像柔边”作为默认值。
- 无效效果值统一回退到 `portrait`。
- WebGL 或导出失败继续使用现有错误提示与恢复路径。
- 不修改知识库、上传、数据库和 `server.ts`。

## 8. 验证

只执行最简单验证：

- 一个预设契约测试，确认正式工作台只有六个预设且默认值有效。
- `npm run lint`。
- `npm run build`。
- 本地上传一张图片，逐个切换六种效果，确认旋转、参数拖动和 MP4 导出入口仍可用。

不增加覆盖率任务，不为每个 Shader 分支编写大量单元测试。

## 9. 非目标

- 不移植黑洞吸积、数字雨、晶体爆碎、星系螺旋和磁力线。
- 不重写正式工作台整体 UI。
- 不把独立 Demo 作为 iframe 嵌入。
- 不同时处理知识库未提交代码或 `server.ts` 模块化重构。
