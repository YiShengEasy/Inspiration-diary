# 粒子参数动画播放预览设计

## 目标

让深度 3D 与粒子溶解两套引擎都能在页面中预览 MP4 的参数动画。动画配置只在用户主动设置时打开，之后播放和导出直接复用，不需要每次重复填写。

## 交互

两套引擎的工具栏统一提供：

- `动画设置`：打开现有参数动画面板，选择多个参数并填写结束值。
- `播放 / 暂停`：直接使用已保存配置预览五秒动画，不弹出设置面板。
- `从头开始`：结束当前预览并恢复预览开始前的真实参数画面。
- `MP4`：直接使用同一份已保存配置导出，不再自动打开设置面板。

播放从点击时的当前参数值开始，使用与导出一致的 `smoothstep` 曲线，在五秒内到达结束值并停在最后一帧。暂停后再次点击继续当前进度；预览结束后再次点击播放，会从真实参数值重新开始，因此可以反复查看效果。

预览只是临时覆盖 Renderer，不改写参数面板中的真实参数。用户拖动普通参数、切换预设、替换图片、切换引擎或点击“从头开始”时，取消预览覆盖并恢复当前真实参数。

## 配置共享与持久化

播放预览和 MP4 导出共享同一份配置，但两套引擎分别保存，因为支持的参数字段不同。

浏览器本地只保存：

- 已启用的参数键。
- 每个参数的结束值。

起始值不保存，每次播放或导出时从当时的真实参数读取。刷新页面、替换图片后配置继续存在。读取配置时按照当前字段定义过滤未知参数，并将结束值限制在当前最小值和最大值之间；本地存储不可用或数据损坏时回退为空配置。

## 架构

共享动画模块增加可持久化配置类型和以下纯函数：

1. 将配置与当前参数组合成运行轨道。
2. 根据字段元数据清洗本地配置。
3. 按引擎读写本地配置。

共享参数面板改为编辑“已保存配置”，打开时回显勾选状态和结束值。确认只保存配置，不自动开始播放或导出。

两套 Studio 各自持有已清洗的动画配置和播放状态，并把运行轨道传给 Renderer。两套 Renderer 使用现有渲染循环逐帧计算五秒动画，不重建 Geometry、不调用 AI、不触发 React 每帧更新。Renderer 通过少量状态回调通知 Studio 当前是播放、暂停还是结束。

MP4 Renderer 继续使用相同的轨道插值工具。导出开始时重新读取当前参数作为起点，保证页面预览和最终视频规则一致。

## 状态规则

- 没有选择参数时，播放只运行现有时间驱动的水波、漂移或闪烁；MP4 保持当前导出行为。
- 预览期间所选参数优先于引擎自动播放对相同参数的控制。
- 播放结束停在结束画面，但真实参数不变。
- 暂停保留当前画面和时间位置。
- 重置、参数编辑、预设切换和图片替换都会取消预览并恢复真实参数。
- 导出期间继续禁止播放、设置、切换引擎和修改参数。

## 错误与兼容

- 非数字结束值不能保存。
- 越界值保存前自动限制。
- `localStorage` 读写异常不阻塞工作台，只保留当前会话配置。
- 旧配置包含已删除字段时自动忽略，不显示错误。
- Renderer 销毁时清理预览状态，不残留动画帧或回调。

## 验证

只增加必要测试：配置清洗、轨道从实时当前值生成、持久化异常回退，以及五秒播放端点。随后运行粒子专项测试、TypeScript 检查和生产构建，不增加覆盖率或逐帧视觉回归测试。
