# Web Markdown GFM 表格修复设计

## 目标

Web 卡片详情正确解析和显示 GitHub Flavored Markdown 表格，并在窄屏下保持详情弹窗布局稳定。

## 解析

保留现有 `react-markdown`，增加 `remark-gfm` 插件。该插件负责将管道表格、对齐标记、删除线和任务列表等 GFM 语法转换为标准 Markdown AST，不启用原始 HTML。

## 渲染

新增一个专用 Markdown 内容组件，统一配置 GFM 插件和表格元素：

- 表格外层只在需要时横向滚动。
- 表格设置最小宽度、边框和稳定的单元格内边距。
- 表头使用明确背景和较高字重。
- 单元格允许自然换行，长单词可以断开。
- 浅色和深色模式分别设置可读的边框、表头和正文颜色。

现有标题、段落、列表、引用、代码块和图片样式继续由详情容器控制。

## 验证

- 使用包含中文、左右对齐、删除线和长文本的 GFM 内容渲染静态 HTML，断言包含 `<table>`、`<thead>`、`<tbody>`。
- 运行 TypeScript lint 和生产构建。
- 检查普通 Markdown 内容仍正常渲染，表格不会撑破详情弹窗。
