# 图片粒子 3D 工作台设计

## 目标

在 Web 端新增独立的“粒子 3D 工作台”。用户上传 JPG、PNG 或 WebP 图片后，浏览器将图片转换为保留原始颜色的 GPU 粒子点云，支持鼠标或触摸拖拽旋转、缩放、深度模式切换、完整参数调节、一键预设和当前画面 PNG 导出。

首版先验证效果与性能；渲染器保持独立，稳定后可直接复用到现有图片详情页。

## 范围

- 新增独立 Web 工具页和项目内入口。
- 提供快速伪深度和 AI 精细深度两种模式。
- 提供完整参数面板及五个一键预设。
- 提供桌面端和移动端交互。
- 提供静态 PNG 导出。
- 不修改图片上传后的原始文件、卡片记录或数据库。
- 首版不提供视频录制、粒子结果云端保存和图片详情页嵌入。

## 技术方案

采用原生 Three.js 与 GLSL Shader，不引入 React Three Fiber。React 只负责工具页状态、工具栏和参数面板，渲染循环及 GPU 资源由独立 Three.js 控制器管理。

核心模块：

```text
ParticleStudio
├── ParticleStudioToolbar
├── ParticleViewport
│   └── ParticleRenderer
│       ├── Three.js Scene / Camera / WebGLRenderer
│       ├── BufferGeometry / ShaderMaterial
│       ├── OrbitControls
│       └── EffectComposer / UnrealBloomPass
├── DepthProcessor
│   ├── FastDepthProcessor
│   └── AiDepthProcessor
├── ParticleControls
├── ParticlePresets
└── ParticleExporter
```

模块边界：

- `ParticleStudio` 管理图片、模式、参数、加载状态和错误，不直接操作 Three.js 对象。
- `ParticleRenderer` 接收标准化的图片像素、深度数据和参数，负责 GPU 生命周期与渲染。
- `FastDepthProcessor` 仅使用浏览器 Canvas 计算亮度、对比度和边缘深度。
- `AiDepthProcessor` 按需加载 Depth Anything V2 Small 的浏览器模型并返回标准化深度数组。
- `ParticlePresets` 只维护参数常量，不耦合界面。
- `ParticleExporter` 从当前渲染结果导出 PNG。

## 工具页布局

工具页使用沉浸式黑色全屏画布，视觉接近参考图：

- 左上角：返回、上传/替换图片、深度模式切换、导出。
- 中央：彩色粒子点云画布。
- 右侧：桌面端完整参数面板，可折叠。
- 底部或顶部：预设快捷入口和当前性能状态。
- 移动端：参数面板改为底部抽屉，画布保持全屏。

图片载入后，粒子从散开状态聚合为图片。切换预设和深度模式时使用平滑插值，避免黑屏或突变。

## 交互

- 鼠标左键拖拽或单指拖拽：旋转观察角度。
- 滚轮或双指：缩放。
- 双击或双触：恢复正面视角。
- 自动旋转可开关，并可调速度。
- 替换图片时保留当前参数；用户可一键重置为预设默认值。
- AI 深度加载期间保留快速深度画面，并显示模型下载或推理进度。

## 参数

### 图像

- 亮度阈值
- 对比度
- 边缘增强
- 透明度过滤

### 粒子

- 粒子密度
- 粒子大小
- 随机散射
- 漂浮速度

### 立体

- 深度强度
- 深度平滑
- Z 轴层数
- 自动旋转与旋转速度

### 辉光

- Bloom 强度
- Bloom 半径
- Bloom 阈值

### 场景

- 背景色
- 相机距离
- 视角复位

高频参数优先通过 Shader Uniform 更新。只有图片、深度源或粒子密度改变时才重建 BufferGeometry。

## 一键预设

- 人像：主体层次清楚，背景粒子更松散。
- 风景：较大深度范围和细粒子。
- 霓虹：高对比、青蓝紫辉光和明显散射。
- 黑白：低饱和、高边缘强度和银白粒子。
- 参考图：黑色背景、青白辉光、适中深度与边缘散射。

预设只是参数集合，选择后用户仍可继续调节单项参数。

## 深度模式

### 快速模式

纯浏览器处理，不调用模型。Canvas 读取缩放后的图片像素，通过亮度、局部对比度和边缘强度计算归一化深度。该模式立即可用，是默认模式和统一降级路径。

### AI 精细模式

按需加载 Depth Anything V2 Small 的浏览器兼容模型：

- 优先 WebGPU，必要时尝试 WASM 后端。
- 显示模型下载和推理进度。
- 利用浏览器缓存避免重复下载。
- 模型和推理代码不进入普通页面首屏包。
- 深度结果只保存在当前页面内存中，不上传至额外服务。
- WebGPU、WASM、模型下载或推理失败时自动回退快速模式，并明确提示原因。

## 粒子生成与渲染

1. 将输入图片按设备性能缩放到安全尺寸。
2. 读取 RGBA 像素，并根据透明度与亮度阈值过滤粒子。
3. 为保留的像素生成 XY 坐标、RGB 颜色、UV、随机种子和目标 Z 深度。
4. 使用 `BufferGeometry` 承载属性，使用一个 `ShaderMaterial` 批量渲染粒子。
5. 顶点 Shader 负责深度、散射、漂浮和聚合过渡。
6. 片元 Shader 负责圆形粒子、软边和亮度输出。
7. `OrbitControls` 负责旋转、缩放和阻尼。
8. `EffectComposer` 与 `UnrealBloomPass` 负责辉光。

粒子颜色来自原图像素。快速模式和 AI 模式只改变 Z 深度，不改变 RGB 数据。

## 性能策略

- 高性能桌面：粒子上限约 120,000，设备像素比最高为 2。
- 普通桌面：粒子上限约 60,000。
- 移动端：粒子上限约 25,000，设备像素比限制为 1。
- 连续帧率低于 30 FPS 时，自动降低粒子密度和 Bloom 渲染质量，并提示当前为性能降级模式。
- 页面隐藏时暂停渲染。
- 离开工具页时释放纹理、Geometry、Material、RenderTarget、Controls 和 WebGL 上下文。
- 处理超大图片前先在 Canvas 中等比缩放，避免一次性读取原始分辨率全部像素。

## 状态与错误处理

- 初始状态：显示上传区、功能说明和示例入口。
- 处理中：显示图片处理或 AI 模型进度，同时保留已有画面。
- WebGL2 不可用：显示浏览器不支持提示，不创建渲染器。
- 图片格式或解码失败：保留当前结果并提示重新选择。
- 跨域图片无法读取像素：提示用户改用本地文件上传。
- AI 模式失败或内存不足：自动回退快速模式，画布不清空。
- Shader 编译失败：显示原图预览和可读错误提示。

## 导出

导出当前相机角度、背景、粒子和 Bloom 合成结果为 PNG。导出时临时按安全范围提高输出分辨率，完成后恢复交互分辨率。首版不导出参数文件或视频。

## 后续接入图片详情页

详情页接入时复用 `ParticleViewport` 和 `ParticleRenderer`，只新增详情页入口与容器适配，不复制 Shader 或深度处理逻辑。首版工具页不修改现有卡片字段，因此后续接入不需要数据库迁移。

## 验收与测试

- JPG、PNG、WebP 可生成保留原色的粒子点云。
- 快速深度立即可用，AI 深度可按需加载并切换。
- 鼠标、触摸旋转、缩放和视角复位正常。
- 全部参数能生效，五个预设可应用后继续调节。
- 入场聚合、模式切换和预设切换无明显黑屏。
- PNG 导出包含当前相机角度和 Bloom。
- AI 失败时自动回退且不丢失画面。
- 桌面和移动端遵循各自粒子上限。
- 页面隐藏时暂停，离开页面后 GPU 资源释放。
- TypeScript 类型检查、生产构建和浏览器交互验证通过。
