# 工具箱三类参考卡设计

## 目标

将工具箱“为你推荐”下原有三张普通图片替换为三个固定、可点击的演示卡片，分别展示图片卡、MD 卡和组合卡，让未登录客户也能理解三类灵感内容的实际形态。

## 卡片布局

沿用现有横向推荐区域，使用已确认的 A 型布局。每张卡包含明确类型角标、视觉预览、标题和类型说明：

- 图片：真实示例图片，标题“自然光影”。
- MD：纸张和文字行预览，标题“周末手记”。
- 组合：双图拼接和视频记录占位，标题“场景组合”。

三张卡都使用本地打包素材，不依赖外部图片请求域名。点击整个卡片进入对应演示详情。

## 演示详情

复用现有 `pages/card-detail/index`，通过 `reference=image|md|combo` 查询参数进入演示模式。演示模式使用内置数据，不请求后端、不要求登录，也不写入缓存。

- 图片详情展示示例图片、摘要和标签。
- MD 详情展示手稿标题、摘要和标签。
- 组合详情展示两张不同角色的参考图，以及一条带提示词的静态视频记录预览。

演示详情隐藏收藏、下载、删除和真实 Card ID 等数据操作，避免客户误以为演示内容属于自己的账号。普通卡片详情流程保持不变。

## 素材

将三张压缩后的 JPEG 示例素材放入 `miniprogram/app/assets/`。单张最长边限制为 640 像素，控制小程序包体积。

## 验证

- 检查三张推荐卡类型、标题和点击参数正确。
- 检查三类演示详情不会触发 `/api/db/cards/:id` 请求。
- 检查普通图片、MD、组合和视频详情分支不受影响。
- 运行小程序 JavaScript 语法检查、JSON 检查、TypeScript lint、生产构建和补丁检查。
