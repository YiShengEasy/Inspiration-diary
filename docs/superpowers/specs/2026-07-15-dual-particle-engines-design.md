# 双粒子引擎工作台设计

## 目标

在现有粒子 3D 工作台中同时保留两套独立底层：

1. 当前正式的深度 3D 粒子引擎。
2. `demos/particle-dissolution/index.html` 的像素粒子溶解引擎。

两套实现通过同一工作台入口切换，但不合并 Renderer、Shader、参数类型或运行状态。

## 已确认范围

- 顶部使用“深度 3D / 粒子溶解”切换，不新增首页入口。
- 切换引擎时继续使用当前上传的同一张图片。
- 深度 3D 引擎保持现有 AI/快速深度、六种预设、3D 旋转、参数控制、PNG 和 MP4 导出。
- 粒子溶解引擎保留 Demo 的灰尘消散、星云扩张、线性扫除、雾化飘落、火焰涅槃。
- 不接入黑洞吸积、数字雨、晶体爆碎、星系螺旋和磁力线。
- 不使用 iframe。

## 架构

`ParticleStudio.tsx` 作为工作台外壳，持有当前图片文件和当前引擎类型。现有实现迁入 `DepthParticleStudio`，新实现放入独立的 `dissolution-studio` 目录。

粒子溶解引擎包含独立的 React 页面、Renderer、Shader、参数类型、预设和样式。它直接从图片像素采样生成平面粒子，不经过深度图、内容蒙版或当前粒子 Worker。图像平面与粒子层使用相同的侵蚀场，保持边界一致。

切换引擎时卸载当前组件并释放动画循环、WebGL、Texture、Geometry、Material 和事件监听，再创建另一套引擎。工作台只共享图片文件、返回入口和引擎切换 UI。

## 数据流与交互

1. 用户上传 JPG、PNG 或 WebP。
2. 工作台保存原始 `File`，并交给当前引擎加载。
3. 切换引擎后，目标引擎自动重新解码同一文件。
4. 普通滑杆只更新 GPU uniform；采样间距变化时才重建粒子 Geometry。
5. 自动播放让侵蚀进度往返循环，复位回到零进度。
6. 粒子溶解引擎支持拖拽旋转、PNG，以及固定当前视角的五秒 MP4。

各引擎参数互不复制。切换回来后以该引擎默认预设重新开始，但图片继续保留。

## 性能与错误处理

- 桌面端限制解码尺寸和最大粒子数量，移动端提高默认采样间距并降低渲染像素比。
- 导出期间锁定引擎切换、上传和参数控制；取消或失败后恢复预览。
- 图片解析或 Renderer 初始化失败时显示局部错误，不影响用户切换回另一套引擎。
- 页面退出、图片替换和引擎切换都必须释放旧资源，避免多个动画循环或 WebGL 上下文残留。

## 验证

- 增加五个溶解预设及其参数契约的最小测试。
- 增加双引擎切换与图片复用的简单组件测试。
- 运行粒子专项测试、TypeScript 检查和生产构建。
- 不增加覆盖率任务或大规模视觉回归测试。
