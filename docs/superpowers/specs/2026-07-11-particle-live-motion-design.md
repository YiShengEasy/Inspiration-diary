# 粒子水波与 MP4 动态导出设计

## 目标

将上传图片转换为一个连续的“原图表面—侵蚀边缘—彩色离散粒子”材质。核心主体保持清晰并产生柔和水波，外围内容逐渐压黑、粒子化并向外离散。所有高频参数必须流畅拖动，当前固定视角可导出为 5 秒无缝循环的 1080p H.264 MP4。

## 已确认的视觉方向

- 使用方案 A：主体稳定、低频柔和水波、外围轻度漂移。
- 红圈只表达内外强度差，不代表圆形遮罩。
- 顶部文字、侧面纹理、肩部和衣服属于原图内容粒子，不是额外白色装饰点。
- 粒子继承原图对应像素颜色；高光可有限变白并触发 Bloom，但不能全部成为白点。
- 保护区域内部以连续图像表面为主，允许少量粒子侵入；越靠外，连续表面越暗，粒子占比越高、密度越低、位移越大。

## 自动保护区域与侵蚀场

上传后由 Worker 根据内容遮罩、亮度、局部梯度、中心注意力和深度生成自动保护区域。区域基底为主体包围盒的各向异性距离场，而非固定圆形；粗噪声改变大尺度轮廓，细噪声产生碎裂边缘，图像梯度保护文字与高光细节。

每个采样点获得连续的 `coherence` 值：

- 高 coherence：保留连续图像表面。
- 中 coherence：图像表面与密集原色粒子交叠。
- 低 coherence：连续表面压黑，原色粒子向外离散。

同一个 coherence/侵蚀场同时控制表面透明度、黑化程度、粒子生成概率、粒子颜色混合、粒子位移和漂浮幅度，避免图片与粒子分层。

## 水波与动态

表面和粒子共享周期性水波函数。水波由低频正弦波和低幅值周期噪声构成，核心主体幅度较小，侵蚀带和外层粒子幅度较大。所有动态使用归一化循环相位，`t=0` 与 `t=5s` 状态一致。

新增参数：

- 水波强度、尺度、速度。
- 侵入范围、边界柔化、不规则度、噪声尺度。
- 外层离散度、原色保留度。

## 流畅参数架构

参数分为两类：

1. 实时 GPU 参数：水波、侵蚀、粒子大小、散射、漂浮、Bloom、深度强度、相机距离等。滑杆事件按动画帧合并，只更新 uniform，不重建数据。
2. 结构参数：粒子密度、深度平滑、Z 轴层数、深度模式。停止输入约 150ms 后在 Worker 中重建，完成前继续显示旧几何体。

深度、遮罩、保护区域和粒子采样全部移出主线程。Worker 结果使用 transferable typed arrays 返回，渲染器原子交换新几何体。目标为桌面 60 FPS、移动端不低于 30 FPS。

## MP4 导出

- 保留 PNG，新增 MP4 导出。
- 输出 1920×1080、30 FPS、5 秒、150 帧、H.264 MP4。
- 导出开始时复制当前固定相机位置、目标和旋转；自动旋转不进入视频。
- 使用确定性时间轴逐帧渲染，不使用实时录屏。
- WebCodecs 负责编码 H.264，MP4 muxer 负责封装。
- 导出期间锁定参数，显示进度并支持取消；批量渲染主动让出主线程。
- 不支持 H.264 WebCodecs 时显示明确错误，PNG 仍可使用。

## 模块边界

- `particleWorker.ts`：深度、内容遮罩、保护区域、侵蚀场和粒子采样。
- `particleWorkerClient.ts`：任务取消、transferable 数据与最新请求获胜。
- `ParticleRenderer.ts`：交互预览、实时 uniform、固定时间渲染和相机快照。
- `shaders.ts`：周期水波、侵蚀、黑化、彩色粒子和外层离散。
- `particleVideoExporter.ts`：150 帧渲染、WebCodecs、MP4 封装、进度与取消。
- `ParticleControls.tsx`：参数分组、实时输入和结构参数重建状态。
- `ParticleStudio.tsx`：上传、Worker、预览、预设和导出编排。

## 错误与资源处理

- 新图片或新结构请求会取消旧 Worker 任务，过期结果不得覆盖当前画面。
- 导出取消、编码失败或组件卸载时关闭编码器、释放帧和临时画布。
- WebGL 上下文丢失、WebCodecs 不可用和内存不足均显示可恢复提示。
- 性能保护仅降低粒子上限、像素比和 Bloom 分辨率，不改变侵蚀形状。

## 验收与测试

- 外层粒子包含原图颜色，不能全部为白色。
- 粒子离主体越远，平均密度下降且平均离散距离上升。
- 侵入范围、柔化、不规则度和噪声尺度分别产生可测差异。
- 实时参数更新不调用粒子重采样；连续结构输入只触发一次延迟重建。
- 表面与粒子在相同 UV/时间点使用同一水波相位。
- 第 0 秒与第 5 秒的周期状态一致。
- MP4 元数据为 1920×1080、30 FPS、约 5 秒、H.264。
- 使用两张目标参考图和图一原始素材完成桌面与移动端视觉回归。

## 非目标

- 本阶段不导出 GIF、WebM 或苹果 Live Photo。
- 不提供手绘保护区域。
- 不接入图片详情页；独立工具稳定后再集成。
